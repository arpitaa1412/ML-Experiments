
# 🥛 Glass Type Classification using Logistic Regression

A beginner-friendly **Machine Learning project** that uses **Logistic Regression for Multiclass Classification** to predict the type of glass based on its chemical properties.

## 📌 Project Overview

Glass can be classified into different types based on its chemical composition and physical properties.

In this project, **Logistic Regression** is used to classify glass samples into different glass types based on features such as refractive index, sodium, magnesium, aluminum, silicon, potassium, calcium, barium, and iron.

The project also includes a **Flask web application** that allows users to enter the required values and get the predicted glass type through a simple web interface.

## 🎯 Objective

The main objectives of this project are:

- Understand Multiclass Classification.
- Learn how Logistic Regression can be used for multiple classes.
- Perform data preprocessing.
- Train a Logistic Regression classification model.
- Predict different types of glass.
- Save the trained model using Pickle.
- Create a Flask web application for prediction.
