# 📱 Social Network Ads Prediction using Logistic Regression

A beginner-friendly **Machine Learning project** that uses **Logistic Regression** to predict whether a user will purchase a product based on their age and estimated salary.

## 📌 Project Overview

Social media platforms display advertisements to users based on their characteristics and interests.

In this project, **Logistic Regression** is used to predict whether a user is likely to purchase a product after seeing an advertisement.

The model uses the user's:

- Age
- Estimated Salary

to predict whether the user will purchase the product or not.

The project also includes a **Flask web application** that allows users to enter their details and get a prediction through a simple web interface.

## 🎯 Objective

The main objectives of this project are:

- Understand Binary Classification.
- Learn how Logistic Regression works.
- Train a machine learning model using the Social Network Ads dataset.
- Predict whether a user will purchase a product.
- Save the trained model using Pickle.
- Create a Flask web application for prediction.
