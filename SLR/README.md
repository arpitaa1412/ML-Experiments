# 📊 Advertising Sales Prediction using Simple Linear Regression

A beginner-friendly **Machine Learning project** that uses **Simple Linear Regression** to predict **Sales** based on advertising expenditure.

## 📌 Project Overview

Advertising plays an important role in increasing product sales. This project uses **Simple Linear Regression** to understand the relationship between advertising expenditure and sales.

The trained machine learning model takes an advertising value as input and predicts the expected sales.

The project also includes a **Flask web application** where users can enter a value and get the predicted sales through a simple web interface.

## 🎯 Objective

The main objectives of this project are:

- Understand the concept of Simple Linear Regression.
- Train a machine learning model using an advertising dataset.
- Predict sales based on advertising expenditure.
- Save the trained model using Pickle.
- Create a Flask web application for prediction.
- Provide a simple HTML interface for users.
