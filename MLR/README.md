# 🏥 Medical Insurance Cost Prediction using Multiple Linear Regression

A beginner-friendly **Machine Learning project** that uses **Multiple Linear Regression** to predict medical insurance costs based on different personal and lifestyle factors.

## 📌 Project Overview

Medical insurance costs depend on several factors such as age, BMI, number of children, smoking habits, and region.

In this project, **Multiple Linear Regression** is used to learn the relationship between these factors and the medical insurance charges.

The trained model can predict the estimated **medical insurance cost** for a person based on the given input values.

The project also includes a **Flask web application** that provides a simple interface for users to enter their details and get the predicted insurance cost.

## 🎯 Objective

The main objectives of this project are:

- Understand Multiple Linear Regression.
- Use a real-world medical insurance dataset.
- Perform data preprocessing.
- Train a regression model.
- Predict medical insurance charges.
- Save the trained model using Pickle.
- Create a Flask web application for prediction.
